# Resume AI Analyzer

AI-powered Resume ATS Analyzer built using Angular + Flask.

## Features
- ATS Score Analysis
- Resume Skill Detection
- AI Resume Rewrite
- Interview Preparation
- Job Recommendations
- Dark Mode UI

## Technologies Used
- Angular
- Tailwind CSS
- Flask
- Python
- OpenRouter API

## Live Demo
Frontend: https://yourfrontendlink.com

Backend:
https://resumeai-2ai9.onrender.com

## Installation

### Frontend
npm install
ng serve

### Backend
pip install -r requirements.txt
python app.py
